更新日志

1.1.4
  · 新增：JRE 直接内置进 exe——四个 Temurin JRE（8 / 17 / 21 / 25）作为资源编译进
    PeterMinecraftLauncher.exe，单文件分发，不再需要 data\jreX.zip 外挂包；
    首次启动自动从 exe 内部解压到 JRE\jreX，已存在则跳过，不覆盖用户文件
  · 改进：释放源优先级变为 data\jreX.zip → exe 内置资源；老的外挂 zip 包仍然兼容，删掉也能跑
  · 修复：源码仓库里 MicrosoftAuth.cs 一处多余引号导致直接编译报错（CS1010），已修正
  · 说明：内置后 exe 约 185MB（四个 JRE 压缩包本身的体积），U盘拷这一个 exe 走就能用

1.1.3
  · 新增：内置便携 JRE 自动释放——启动时检查 JRE\jre8 / jre17 / jre21 / jre25 是否完整，
    缺失则从 data\jreX.zip 自动解压释放，已存在则跳过，不覆盖用户文件
  · 新增：随程序分发四个 Temurin JRE（8 / 17 / 21 / 25），拿到程序就自带 Java，
    不需要联网下载；JRE 目录已存在时直接跳过

1.1.2
  · 新增：Java 扫描兼容 JRE\ 目录名——之前只认 Java\ 目录，现在 Java\ 和 JRE\ 两个目录下的 jre* / jdk* 都会被自动识别
  · 修复：用户把便携 JRE 放在 JRE\jre8 这类目录下时启动器扫不到的问题

1.1.1
  · 新增：按游戏版本自动匹配 Java（Java 8 / 11 / 17 / 21 / 25 全部可用），不再限定 1.16.5
  · 新增：不再需要手动装 Java。删掉「安装 64 位 Java 8 / 安装 32 位 Java 8 / 部署便携 Java」三个按钮，
    换成一个「根据我的游戏版本自动选择 Java」：本机有匹配的直接切过去，没有就自动下载
  · 新增：自动下载 JRE（清华 TUNA 镜像优先，Adoptium 官方 API 兜底），下载后解压到 Java\jre{主版本} 并自动校验能否运行
  · 新增：Java 需求优先读版本清单的 javaVersion.majorVersion，读不到才按版本号映射（1.16→8、1.17→17、1.18~1.20.4→17、1.20.5+/1.21→21）
  · 新增：多游戏版本支持。版本列表改为按清单扫描，inheritsFrom 会向上合并父版本（Forge / Fabric / OptiFine）
  · 新增：兼容老格式 minecraftArguments（1.12 及更早、部分 Forge）
  · 新增：Java 探测支持 11 / 17 / 21 / 25 以及 Microsoft / Zulu / Corretto / Liberica 等发行版目录
  · 改进：启动页直接显示「Java 版本（匹配 Java X / 需要 Java X）」，一眼看出对不对
  · 改进：切换游戏版本后自动重新匹配 Java；启动时 Java 不匹配会问你要不要自动换，不再只是警告
  · 改进：释放时跳过官方启动器的 webcache 浏览器缓存，少复制几十 MB 垃圾
  · 移除：Java\Setup.exe / Setup-x86.exe 安装包调起、便携 JRE 复制部署（已被自动下载取代）
  · 说明：联网只有两项——微软正版登录、按版本下载 JRE；仍然不下载游戏文件、不联机
  · 实测：自动下载 Java 17（17.0.21 x64）9 秒完成；真实 1.16.5 启动 14 秒出现游戏窗口

1.1.0
  · 重写为图形界面启动器（Peter Minecraft launcher），不再依赖 bat 菜单
  · 新增：首次启动自动释放 .minecraft（支持 zip 包 / 文件夹两种释放源，带进度与标记文件）
  · 新增：一键安装 Java 8（64 位、32 位各一个按钮）+ 便携 JRE 一键部署
  · 新增：微软正版账户登录（设备码登录 / 旧版弹窗登录两条链路），不再局限于离线登录
  · 新增：离线昵称设置，自动生成与 Java 一致的离线 UUID
  · 新增：最大 / 最小内存滑块分配，直接写入 config.ini
  · 新增：日志查看页（游戏输出 mc_log.txt、latest.log、启动器日志）
  · 新增：Java 自动探测（注册表 / Program Files / 官方启动器 runtime / PATH / JAVA_HOME）
  · 保留：系统级命令窗口（管理员 cmd），等同旧版 [3]
  · 保留：config.ini 的 username / maxmem 键名，旧配置可直接用
  · 保留：Games\Start.bat 的启动逻辑（Java 8 检测、natives、classpath、2G 内存）
  · 界面：深色 + 草绿配色，自绘按钮 / 卡片 / 滑块，无边框窗口
  · 说明：除微软正版登录外无任何联网功能，不下载游戏文件、不联机
  · 界面：下拉框改为自绘深色控件，不再出现系统白底
  · 界面：标题栏版本角标 v1.1.0 修正被标题遮挡的问题
  · 修复：输入框构造时 OnResize 空引用导致启动崩溃
  · 修复：Java 版本解析改用正则 + 文件版本兜底，坏掉的 javapath 壳子会标「无法运行」
  · 修复：游戏日志改为共享读写，游戏运行中也能在启动器里查看
  · 实测：在「L: 畅玩 Minecraft」的 1.16.5 上离线启动成功（日志出现 Setting user: Player）
